## ✨ Features

| Feature | Description |
|---------|-------------|
| 🧠 **AI-Powered OCR** | Tesseract.js engine reads handwritten prescriptions |
| 🫀 **3D Body Map** | Interactive Three.js human body with clickable organs |
| 💊 **Medication Detection** | Auto-identifies common medications from text |
| 🎨 **3D Animations** | Floating organs, DNA helix, particles, heartbeat effects |
| 📱 **Fully Responsive** | Beautiful on desktop, tablet, and mobile |
| 🔒 **HIPAA-Aware** | No data stored on servers, client-side processing |
| ⚡ **Instant Results** | Get prescription analysis in under 3 seconds |
| 📥 **Export Reports** | Download prescription reports as text files |

## 🛠️ Tech Stack

- **Three.js** — 3D WebGL animations (heart, DNA, organs, particles)
- **Tesseract.js** — Optical Character Recognition engine
- **Vanilla JavaScript** — Zero framework dependency, pure performance
- **CSS3** — Advanced animations, glassmorphism, responsive grid
- **WebGL** — Hardware-accelerated 3D rendering

### Local Development
```bash
# Clone the repository

# Navigate to project
```

## 🎮 Interactive Features

### 3D Body Map
- Click on organs to see related prescription information
- Drag to rotate the 3D body model
- Organs pulse and glow on interaction

### AI Scanner
- **Upload** any prescription image (JPG, PNG, PDF)
- **Drag & Drop** support
- **3 Demo prescriptions** (General Medicine, Cardiology, Neurology)
- **Real-time OCR** processing with step-by-step animation
- **Auto medication detection** for common drugs
- **Download reports** as text files

### Visual Effects
- Particle background with mouse parallax
- Cursor glow trail effect
- 3D tilt on feature cards
- DNA double helix animation
- Heartbeat-synced logo
- Floating pill capsules
- Smooth scroll animations
